# 포트폴리오용 저비용 AWS 배포 진행표

확인일: 2026-10-22

## 현재 상황과 선택

- 사용자는 개인 AWS 계정이 있으며 서버 배포 경험은 없다.
- 목적은 취업 포트폴리오와 배포 경험이다. 비용을 최대한 줄이고 한 단계씩 진행한다.
- 도메인 보유 여부, 계정의 무료 크레딧/무료 플랜 적용 상태, 실제 월 지출 상한은 아직 확인 전이다.
- 기존 `docs/deployment.md`의 ALB + EC2 + RDS 구성은 확장용이다. 첫 배포에 그대로 만들지 않는다.
- 첫 후보는 Lightsail Linux 2GB, 공인 IPv4 포함 서버 한 대다. 공식 기본요금 월 USD 12. 세금, 스냅샷, 별도 저장소, 도메인, 전송량 초과 비용은 별도다. 무료 혜택은 해당 계정 콘솔에서 확인한다.
- 화면(Next), API(Express), PostgreSQL, Redis, HTTPS 프록시를 같은 서버에서 실행하는 구성을 준비한다. 메모리를 많이 사용하는 이미지 빌드는 로컬 또는 CI에서 하고 서버는 실행만 한다.
- 현재 로컬 유휴 측정: 화면 약 43MiB, API 약 122MiB, DB 약 44MiB, Redis 약 10MiB, 프록시 약 12MiB. 이 수치는 부하 테스트나 2GB 서버의 용량 보증이 아니다.
- 한 서버가 중단되면 서비스와 DB가 함께 중단된다. 포트폴리오용 가상 데이터로 시작하며 DB 백업·복구를 검증한다.

공식 근거:
- https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-bundles.html
- https://aws.amazon.com/lightsail/pricing/
- https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html

## 진행 순서

| 순서 | 쉬운 설명 | 담당 / 완료 기준 |
| --- | --- | --- |
| 1 | 돈이 얼마나 나오는지 먼저 확인하고 알림 설정 | 사용자: Billing에서 현재 비용·무료 혜택 확인, Budgets 비용 알림 |
| 2 | 배포할 코드를 점검 | 개발: 주민/관리자 흐름, 권한, 로그인 갱신, 자동 테스트, 수정 기록 |
| 3 | 서버 실행 준비물을 완성 | 개발: 단일 서버 Compose·HTTPS·환경변수·초기 관리자·백업·배포 절차 |
| 4 | AWS에서 작은 컴퓨터 한 대 빌리기 | 사용자: 서버 가격 확인 후 Lightsail 생성, 서울 리전, 고정 IP |
| 5 | 접속 주소와 자물쇠(HTTPS) 연결 | 도메인 보유 여부 확인 후 DNS와 인증서 설정 |
| 6 | 프로그램과 데이터베이스 올리기 | 이미지 전달, DB 마이그레이션, 초기 관리자 생성, 데모 단지/주민 승인 |
| 7 | 외부 인터넷에서 최종 확인 | 로그인→민원→처리→알림→공지, 이미지 업로드, 재시작·백업 복구 |
| 8 | 이력서에 설명할 근거 남기기 | 실제 배포 URL, 구성도, 배포/복구 기록, 실제 검증 결과 |

## 사용자가 지금 할 한 가지

AWS 콘솔의 검색창에서 **Billing and Cost Management**를 열고, **Budgets(예산)**에서 비용 예산을 만든다.
처음에는 월 **USD 15**를 알림 기준으로 제안한다. 이는 확정 운영비나 자동 지출 한도가 아니다.
실제 비용 50%와 80%, 예상 비용 100% 알림을 받을 이메일을 등록한다.
계정의 무료 플랜/크레딧이 보이면 잔액·만료일도 확인한다. 비밀번호·액세스 키는 공유하지 않는다.

예산 알림은 과금을 자동으로 멈추지 않으며 집계가 지연될 수 있다.
서버 생성은 최종 가격과 계정 혜택을 확인한 다음 단계에서 한다.
현재 화면의 Agent Toolkit 연결은 이 배포 절차의 필수 단계가 아니다.
스크린샷의 현재 리전은 시드니(ap-southeast-2)다. 서버 생성 때 서울(ap-northeast-2)로 선택한다.

## 초기 최고관리자 생성

공개 `POST /api/auth/signup/super-admin` 경로는 제거했다.
서버에서 `node dist/cli/bootstrap-admin.js`를 실행하고 표준입력으로 JSON을 전달한다.
필드: username, password, name, contact, email, role=SUPER_ADMIN, joinStatus=APPROVED.
비밀번호를 명령 인자나 저장소 파일에 넣지 않는다.
기존 최고관리자가 있으면 생성하지 않는다. 이후 관리자 가입과 단지 승인은 최고관리자 화면에서 처리한다.

이 문서는 준비 계획이다. Lightsail 자원 생성·단일 서버 운영 구성·HTTPS·S3 업로드는 아직 검증하지 않았다.
