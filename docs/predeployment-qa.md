# 배포 전 검증 기록 — 2026-10-23

| 문제 | 수정 |
| --- | --- |

| 로그아웃 직후 다시 로그인하라는 팝업 | 기본 권한 이동에서 불필요한 팝업 제거 |
| 공개 최고관리자 가입 API | 경로 제거, 서버 초기 관리자 명령 추가 |
| 비공개 민원 수정 화면의 선택 상자가 공개로 표시됨 | 비동기로 읽은 실제 공개 상태를 제어값으로 연결 |
| 빈 내용·연속 클릭·저장 실패 안내 부족 | 필수 입력 검사, 제출 중 잠금, 오류 시 입력 유지 |
| 민원 상세 오류가 무한 로딩으로 보임 | 오류 설명과 목록 복귀 링크 |
| 민원 분류 COMPLAINT·원시 UTC 문자열 노출 | 한국어 분류·한국 시간 표시 |
| 공지 날짜 Invalid Date | 이미 Z/오프셋이 있는 값에 Z를 중복 추가하지 않고 관리자·주민 날짜 표시 통일 |
| 좁은 화면의 공지 표가 과도하게 압축됨 | 표 최소 너비와 영역 내 가로 스크롤 |
| 테스트가 데모/운영 DB를 지울 수 있음 | setup에서 testdb 또는 *_test DB 이름만 허용 |

최고관리자 명령의 잠금 쿼리는 void 결과 대신 정수 열을 반환하도록 수정했다.
실제 빈 PostgreSQL DB에서 첫 실행 성공(0), 두 번째 실행 거절(1), 출력에 비밀번호가 없는 것을 확인했다.

## 검증 결과

- PostgreSQL 16·Redis를 별도 컨테이너로 준비하고 마이그레이션 26개 적용.
- 전체 Jest 18개 스위트, **249개 테스트 통과**. 기존 240개에 최고관리자 공개 가입 차단 1개, 세션 4개, 공지 날짜 4개 추가.
- 백엔드 타입 검사·빌드, 프런트 lint와 Docker 내부 Next 빌드 통과. 양쪽 이미지 재빌드 후 로컬 Compose 반영.
- 실제 브라우저: 주민 로그인 → 민원 작성 → 비공개 수정 → 재편집 시 비공개 유지.
- 실제 브라우저: 관리자 로그인 → 민원 선택과 제목 제안 → 공동 문제 생성 및 입력란 이동 → 처리 중 → 완료 → 공지 작성 확인 → 초안 → 최종 게시.
- 실제 브라우저: 관리자와 주민 목록의 정상 한국 시간, 로그아웃 시 팝업 없이 로그인 화면, 주민의 처리 완료 이력 확인.
- 공지 초안에는 공유 설명·완료 이력만 들어가고 비공개 민원 원문은 포함되지 않음을 확인.
- 테스트용 민원 1건·공동 문제 1건·공지 1건·DB 알림 5건을 정확한 ID와 제목 검증 후 정리. 기존 민원 3건·공동 문제 1건 보존.
- 모든 화면·모바일 기기·실제 고령 사용자 조사, 부하 테스트, AWS 운영 검증을 완료한 결과는 아니다.

## 공개 배포 전에 남은 작업

1. 기존 민원 생성/삭제, 공지·댓글 등 전체 API의 단지·대상 권한 검증 보강. 이번 인증 수정이 기존 모든 API의 접근 통제를 해결하지 않는다.
2. 실제 AWS 비용/무료 혜택, 도메인 보유 여부 확인 후 단일 서버 Compose·HTTPS·배포 경로 확정.
3. S3 실제 업로드 권한·이미지 조회, 서버 재시작·DB 백업/복구 검증.
4. GitHub PR의 CI 확인 후 병합. 로컬 테스트 통과와 원격 CI 결과는 구분한다.

기존 ALB·RDS 배포 문서보다 `docs/deployment-portfolio.md`의 저비용 첫 배포 순서를 우선한다.

- 2026-10-23 검증 전용 PostgreSQL/Redis 컨테이너를 제거했다. 테스트가 일반 DB 이름을 거절하는 것도 실제 실행으로 확인했다. 로컬 데모 서비스는 계속 실행 중이다.
